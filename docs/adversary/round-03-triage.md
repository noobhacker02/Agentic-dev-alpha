**FIXED**, **SPEC** (the claim is narrowed and the limit written down), **SCHEDULED** (a stage is named), **REJECTED**, as in rounds 1 and 2. A row says FIXED only in the commit that fixes it, and every FIXED row has a test that
failed on the code before (each new section was run against the previous `src/` and failed there) and, for the browser rules, a mutant of the new code that the test catches.

The agent found one more thing by showing that the fix I first reached for was wrong: A52 suggested holding every request that has no frame, and a probe (a shared worker's `fetch` against a context-level `route()`)
showed those requests never reach `route()` at all. The fix is therefore to remove the constructor, not to widen the hold.
